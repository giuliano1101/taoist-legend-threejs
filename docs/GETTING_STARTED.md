# 启动、操作与常见问题

## 环境

- Node.js 22 或更新版本。
- 启用硬件加速的 Chrome / Edge，支持 WebGL2。其他现代浏览器可尝试，但不是本次验收基线。
- 资源规模约 86 MiB，主要来自角色和高斯点云；首次 GPU 准备需要时间。

不需要 npm 安装、Blender、Python、AI 权重或 API Key。`dist` 是已经可运行的源文件，不需要构建。

## 启动

在项目目录运行 `npm start`，打开 `http://127.0.0.1:4173`。Windows 可双击 `Start-Game.cmd`。

若端口占用，设置 `PORT`，例如 PowerShell：

```powershell
$env:PORT = '4180'
npm start
```

服务只监听本机回环地址，不默认开放到局域网。

## 加载流程

封面会准备角色、怪物、点云、声音、图片、字体和第一帧 GPU 资源。语音先结束时继续等待资源；资源先结束时提示按任意键或点击提前进入，否则等加载句结束自动进入。进入后播放开场句。

浏览器可能阻止自动播放；按键或点击可解锁。进入动作不会顺带触发攻击或跳跃。

## 可选：Windows 启动器

仓库提供源码，不跟踪生成的 EXE。Windows 已安装 .NET Framework 编译器时：

```powershell
powershell -File tools/Build-Launcher.ps1
.\TaoistLegend.exe
```

启动器开启本地服务，再打开 Chrome/Edge 应用窗口。使用专用浏览器数据目录，并允许此游戏窗口自动播放声音；仍需要 PATH 中的 Node.js。图标与游戏封面属于相同的公开前素材审核范围。

## 战斗

左键即时近身劈砍，造成 25 伤害；Q 火球 50；E/J 四式剑招依次 35/40/50/65。护士 100 气血，主角 100，每次抓击损失 16。蓄力期间可以后退躲避或攻击打断。R 恢复第一波、角色气血和位置，并清理技能及破土残留。

开局先留短暂空场，之后 6 只护士分批出土。杀光并消散后继续下一波。

## 常见问题

- **不能双击 HTML？** ES 模块、点云和音频需要 HTTP 加载，请启动服务。
- **第一声没有播放？** 浏览器自动播放限制，先按键/点击，或使用可选启动器。
- **白屏/不能创建 3D？** 查看浏览器 WebGL2 与硬件加速是否可用，避免远程桌面中的软件渲染限制。
- **如何完整重播？** R 只重置战局；Ctrl+R 刷新加载与开场。
- **手机能玩吗？** 有触屏横竖布局，真实设备性能尚未全面验证。
- **能直接公开全部素材吗？** 当前不能从许可记录得出这个结论，先完成 `PUBLIC_RELEASE_CHECKLIST.md`。

## 本地检查与 CI 模板

运行 `npm run check` 与 `npm test` 可完成仓库审计和服务测试。`docs/ci-check.example.yml` 提供 GitHub Actions 配置模板；当前没有启用自动工作流，因为归档所用登录不包含 workflow 权限。以后确有需要时，由维护者用具备相应权限的方式将模板放入 `.github/workflows/`。此操作与仓库是否公开无关。
