# 架构与维护位置

## 一帧中发生什么

输入更新玩家意图与攻击缓冲；导航约束位置并采样地面；角色动作、衣摆与武器跟随；相机按越肩摇臂避障并计算准星目标；敌人状态、路径和命中推进；特效与声音响应事件；最后同步 UI 并进行点云与后处理渲染。

## 模块

| 源文件（位于 `dist/`） | 职责 |
| --- | --- |
| `game.js` | 场景入口、输入、战斗调度、暂停、重置、加载协调 |
| `character.js` / `locomotion.js` | 原道士 FBX、原生动作片段、关节方向重定向 |
| `cloth.js` / `materials.js` | 衣物身体/墙地约束、皮肤布料金属材质、消散支持 |
| `navigation.js` | 地面采样、分段移动、相机约束、地图射程预算 |
| `camera-rig.js` | 越肩构图、上下瞄准、摇臂碰撞 |
| `enemies.js` / `enemy-routes.js` | 六敌人波次、变化路径、攻击、受击与死亡 |
| `zombie-motion.js` / `ground-emergence.js` | 拖行 IK、支撑脚、抓击、破土、地面特效 |
| `combat-effects.js` / `flame.js` / `crescent-qi.js` | 连续弹道、火焰、月牙、粒子、命中和去重 |
| `atmosphere.js` | 点云深度参与的体积雾、统一色调、补光与泛光 |
| `sound.js` / `horror-bgm.js` / `zombie-voices.js` / `hero-voices.js` | 合成动作音效、本地音频、空间衰减、混音及暂停续播 |
| `launch-screen.js` | 真实分项加载、首帧就绪、语音与资源双条件进入 |
| `ui-aaa.js` / `ui-coherent.js` / `enemy-health-ui.js` | HUD、统一菜单、字幕、状态和头顶血条 |

主要运行资产清单见 `runtime-manifest.json`。主角使用 FBXLoader 直接保留绑定；护士使用 GLB 内嵌贴图，所以不再另附重复 PNG。

## 重要约束

- 原骨轴不同，动作重定向按关节方向处理，不能直接套另一骨架的局部旋转。
- 点云场景没有自动生成游戏碰撞，导航 JSON 提供逻辑约束。
- 技能飞行范围来自当前地图，变更地图后需检查准星、怪物与镜头。
- 近战与剑气共享攻击编号；同一招不能重复结算同一目标。
- 暂停需要同步冻结战斗、怪物、特效与声音，重置需要清理残留。
- 字体采用 WOFF2；运行资源与第三方库本地保存，不需要网络下载。

## 已知限制

SPZ 含烘焙光照；衣摆不是完整自碰撞布料；HUD 的真气反馈不等于已有独立成长或装备系统；怪物追击使用代码逻辑；手机布局检查不等于所有设备性能承诺。
