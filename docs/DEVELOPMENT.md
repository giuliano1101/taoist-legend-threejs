# 从动作试验场到古巷战斗

这份摘要只保留技术与设计过程，不包含私人对话、订单、网盘提取码、本机绝对路径或账户信息。

1. **最小原型。** 最早的输入资产有模型贴图但无骨骼动画，先用基础骨架与蒙皮建立空场景中的走、跑、击打、跳跃和键鼠控制。该旧模型已被替换，不进入当前仓库。
2. **替换道士与古巷。** 新资产已有 Biped 骨骼。Blender 导入会改变其绑定显示，浏览器直接加载 FBX 正常，因此保留原绑定。Spark 接入约 200 万高斯点的 SPZ 环境。
3. **让场景可走。** 从点云分析地面和障碍，建立导航网格，加入地面采样、墙体滑动、端点约束、相机避障。渲染场景与逻辑地图分工。
4. **动作、衣物与法术。** 主角放大到约 2.14 米；走跑参考重定向到原骨架，加入衣摆胶囊与墙地约束。施法和四式剑招利用原时间线片段，配合输入缓冲、剑气、火球与本地合成音效。
5. **渲染调试。** 雾硬边来自旧碰撞代理深度，改用点云透明度加权深度与人物几何深度，加入 28 步体积雾和深度引导上采样。整体曝光与冷暖灯光再次校准。
6. **战斗闭环。** 护士保留 110 根骨骼，从无动画资产制作追近、抓击与受击。加入真实伤害、打断、气血耗尽、1.65 秒溶解、同招去重与连续弹道碰撞。
7. **修正“看起来不对”。** 主角手肘、身体与头部朝向逐项校正；护士通过骨轴校准、世界坐标支撑脚与双骨 IK 修正翘脚和滑步。抓击按蓄力、发力、随动和收势分段。
8. **瞄准与特效。** 镜头改为越肩，弹道来自手部到准星真实目标。体积火焰替代实心球；月牙曲面、收尖刃口、流动细丝与粒子替代圆环。
9. **地图与玩法迭代。** 活动面积约 46 → 74 → 173 平方米，可走纵向约 54.7 米。修复仍沿用旧寿命的火球。怪物从 4 只试到 12 只，最终每波 6 只，空场后错峰破土；左键最终改为普通劈砍，Q/E 分别控制技能。
10. **美术与声音收尾。** 生图先定 HUD 方向，再拆为透明图标、面板和横幅。封面重构为 4:3，控制区在画内。声音增加 96 秒本地配乐、女性低吼与远哭、参考音色合成台词。
11. **进入流程。** 资源、首帧和语音共同决定进入；100% 可任意键提前进入，输入不穿透。加入可选 Windows 图标启动器，保留普通浏览器的交互解锁路径。
12. **私有归档。** 只保留使用中的运行依赖；删除机器专用路径与 FBX 元数据；补充文档、公开前权利清单、维护检查和展示图。

这是迭代完成的可玩原型。宣传插画与实机截图在 README 分开标注；公开许可准备仍需单独完成。
